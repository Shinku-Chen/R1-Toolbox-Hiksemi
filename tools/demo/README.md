# 本地演示环境

在一台普通电脑上运行完整的 R1 Toolbox 面板：真实网页服务 + 真实小屏 UI + 会变化的假 NAS。
不需要 Docker、NAS 或任何硬件；所有风扇、SMART、灯光、电源操作都在内存里模拟。

```sh
python scripts/build-panel.py          # 首次或改过 ui/panel-src/ 后
python tools/demo/run.py               # 仅本机访问
python tools/demo/run.py --host 0.0.0.0 # 允许同一局域网的电脑/手机访问
```

启动后终端会打印地址：

| 入口 | 地址 | 内容 |
|---|---|---|
| 网页面板 | `http://127.0.0.1:18732/` | fnMonitor 面板、R1 风扇/灯光设置、容器与配对 |
| 小屏触摸 | `http://127.0.0.1:18731/` | 五标签触摸界面、控制中心、详情页 |

端口被占用时换一组：

```sh
python tools/demo/run.py --screen-port 28731 --web-port 28732
```

## 怎么联动

两个入口共享同一份假 NAS 状态：

1. 小屏「控制中心 → 网页设置 → 生成一次性配对码」，在网页面板输入五位数字即可解锁设置。
2. 小屏调亮度/息屏/电源，网页 `/api/r1` 与设置页同步；网页改风扇模式、曲线、温度设备，小屏「控制中心 → 风扇状态」的只读状态同步。
3. 网页调整灯光策略，小屏灯光状态和颜色同步；容器操作在两端都能看到状态变化。

演示数据每 1.5 秒变化一次（CPU、温度、网络、历史采样、风扇参考温度），用于观察趋势、告警阈值和风扇输出变化。

## 演示与真实的差异

- 不执行真实电源操作：倒计时结束后只标记“演示环境未执行真实电源操作”。
- 风扇转速始终显示未知，回路目标百分比用于演示曲线与档位；不会伪造 RPM。
- 容器、虚拟机、SMART 都是固定假数据，删除演示目录不会影响真实 NAS。
- 网页面板仍走真实配对与 CSRF；小屏 API 由演示进程注入本地控制令牌，只应在可信电脑/局域网使用。
- 状态默认在临时目录，重启即重置；需要保留可加 `--data-dir ./demo-state`。

## 代码

- `fake_nas.py`：共享内存状态、每分钟采样、风扇/灯光/电源/容器模拟。
- `server.py`：复用真实 `runtime/web_config.py` 起网页面板，另起小屏 HTTP 服务并注入令牌。
- `run.py`：命令行入口。

演示工具不属于镜像交付内容，也不访问宿主硬件。
