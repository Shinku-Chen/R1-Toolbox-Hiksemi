宿主小屏任务由一次性 Docker 项目通过 `nsenter` 进入宿主 PID、mount、UTS、cgroup 命名空间及根目录后执行，network 和 IPC 已共享。

- image 模式从当前镜像复制 UI 包，在确认 tmpfs 后展开到 `/run`；校验 SHA256、完整清单与缓存，无需上传页面。
- directory 模式沿用 NAS 自有完整前端目录。diagnostic 仅检查，不停小屏。旧 NEW_HTML 参数拒绝执行。
- 小屏临时服务只读挂载前端；镜像模式还运行原创 Python 只读采集与 AppRun，随小屏生命周期退出。容器结束不影响宿主服务。
- 启动前验证真实绑定与只读状态，启动后验证 `/proc/PID/root` 视图、cgroup 与连续 3 秒存活。
- 不写原小屏文件或启动脚本；失败尽力无绑定启动原 AppRun。成功记录按 boot ID、任务版本、镜像和模式配置去重。
- 恢复官方界面需停用项目自动启动或删除项目后重启 NAS；仅停止容器或切诊断不会立即撤销现有服务，也不会自动启动官方窗口。

准备、依赖和限制见 [部署说明](README.md)。
