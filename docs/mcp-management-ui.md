# MCP 与 API 管理界面

网页“API 管理”卡片直接提供 MCP／REST 服务开关。首次读取服务状态时不读取 Token 列表；点击开关立即通过所有者授权的 `/api/services/mcp` 保存，不弹出操作确认。请求期间禁止重复点击，保存失败显示原因并读取一次真实状态；不自动重放写请求。关闭服务会保留已有 Token，客户端立即停止访问。

卡片提供三个独立入口，弹层内可直接切换页面：

- **添加 Token**：按只读、读写、管理员角色，选择功能、具体工具、文件范围、已登记 Docker 项目、来源 IP／网段和有效期。提高角色等级不自动增加工具权限；新增工具默认不选。
- **Token 管理**：查看安全元数据，编辑授权、暂停／启用、轮换或撤销。轮换和撤销保留明确确认；权限修改不隐式延长有效期。撤销后不提供恢复入口。
- **Token 操作**：查看当前设备连接地址、动态工具能力目录、文件／Docker 接口定义与最近调用记录。此页不收集旧 Token，不用网页会话代理机器调用。接口定义依然按需读取。

Token 明文仅在创建或轮换后的专用窗口显示一次。复制由用户明确点击；关闭或按 Escape 会清空 Token 及客户端配置字段，不写入浏览器存储。关闭后重新进入添加页使用只读角色与状态读取工具，不保留上次的表单草稿或明文密钥。

文件授权入口说明固定边界 `/drives/*/Users/`，只展示后端核验的根目录；子目录使用相对 POSIX 路径。多个范围取并集，下级只读不能收窄上级读写。界面不以角色代替具体工具或资源授权，不将尚未接入的写入、安装或文件能力宣传为可用。

界面复用 fnMonitor 设置卡片、弹层、输入控件和按钮。三个页面不同时展开；手机使用单列入口、单列工具与 Token 元数据，长地址、范围和记录可换行，在 320px 宽度无需横向滚动。

验证：`node tests/check_api_management.cjs` 覆盖直接开关读取／保存失败、状态回滚、防重复提交、三个入口隔离、创建／编辑／停用／启用／轮换／撤销、逐工具授权、秘密清理及窄屏布局；`node tests/check_service_settings.cjs` 覆盖服务入口与 API 卡片之间的状态同步。
