# 用户需求、附件与实现核对

核对日期：2026-10-28。基线为 `ba49f43`；“本轮”指其后的集成监控网页、灯光策略与历史统计实现。本文记录代码与已收到的设备证据，**不把按钮存在、API 名称存在、替身测试通过或构建成功当成海康实机效果验证**。

来源包括对话中的部署／少改宿主／双路独立温控要求，最早 `index.html`、R1 Panel 1.1.7、R1 Toolbox 4.8.10，以及新附件 `f4251f80-9f71-41a1-91d9-24869c4463a4-1793117236392.html` 与 `c04366bd-986a-45cb-bea4-7355766e82e7-1793117236395.html`。只静态阅读附件，没有执行其页面脚本／二进制、请求外部服务、复用激活逻辑或复制其整套界面。早期包与官方接口证据分别见 [附件审查](attachments.md) 和 [原厂接口审查](histor-interfaces.md)。

## 双路风扇：最初方案与当前能力不能混淆

用户明确要求 **CPU 与系统两路分别手动／温控、多选温度源取最高、各自三档阈值**，只提供原厂固定系统档位不能满足。最初发现的原厂 `fan_mode` 只有系统风扇低／中／高／自动；后来追踪 CPU 独立原厂线程与 initrd 支持驱动，才形成当前受监督接管。`ba49f43` 已经包含这套独立控制，不应再把本轮之前描述成“只有原厂档位”。

| 功能／证据 | `ba49f43` 实际 | 本轮保持的边界 |
|---|---|---|
| 两路分别设置原厂／固定输出／温控 | 已实现，网页双卡与小屏分路详情 | 保留；CPU 和系统是原厂逻辑通道名，机械对应仍待观察 |
| 每路独立多选 CPU／主板／硬盘来源 | 已实现，取有效原始 °C 最高值，不按不同来源做“归一化温度” | 本轮灯光可复用同来源目录，但不改风扇规则 |
| 静音／普通／全速三阈值 | 已实现 Ts<Tn<Tf、15–85°C，静音／普通 50–100%，全速 100%，迟滞与缺测保护 | 保留；不照搬附件 raw25／85 之类可能停扇的输出 |
| CPU 高温／缺测保护 | 已实现独立保护；即使固定输出或只选硬盘，仍检查 CPU | 保留，不因监控阈值调高而放松保护 |
| 不与原厂温控无限抢写 | RAM 窄适配层仅处理已接管 0x5798／0x5799；未选路与休眠相关请求透传；原厂模式变化主动释放 | 保留；对不改模式的稀疏 direct 写有有界重申，仍可能一轮短暂竞态 |
| 保留原厂二进制与配置 | 不覆盖原厂文件，不修改 `fan_mode`，不重启 emhistor；重启同一个 temp_control 加载 RAM shim | 保留；重启温控执行者会重建其硬盘休眠计时，不能隐瞒这一副作用 |
| 失败恢复 | 独立宿主 watchdog、5 秒短租约、身份校验、请求安全高档、恢复原进程和既有系统策略；可重试恢复 | 保留；未确认必须报错，断电／设备失效无法保证机械恢复 |
| 固件与驱动身份 | 完整 loaded GNU note 已由用户核对为支持版 `c909da338be2c4700bb00b233cb189e7a32655b7`；temp_control 另有精确 SHA 约束 | 这是可用 ABI 证据，不代表本版所有控制都已肉眼验证；未知模块／固件拒绝接管 |
| 原厂模式读取 | 用户实机 Unix GET 已返回 `b'5'`，与 auto 配置一致 | 已验证协议读取；不能据此声称手动切档或独立温控效果已经实测 |
| 原厂 RPM | 用户旧 product_test 返回 `cpu[-1]-sys[-1]`，两次旧 ioctl 报错 | 仍未知；旧 RPM 失败不反证 initrd 驱动写 ioctl 不支持，也不把 −1 改成 0 |
| 标准 hwmon IT87 曲线 | 通用适配仍在，当前官方系统无 IT87 PWM | 有可信通道才开放，不加载模块／裸端口探测；不能把它当成本机独立调速已经验证 |

历史中的 `fan_*_target_percent` 始终称请求输出。原厂 RPM 未提供时，页面不应以目标百分比、CPU MHz 或动画转速冒充 RPM。详细控制与恢复见 [独立温控指南](fan-policy.md)。

## 验证层级

已经收到的真机证据包括：小屏已能显示并切换页面；实际加载 hikio note 匹配支持版；原厂 Unix GET 为 `5`；旧 RPM 读取失败。**本轮新增监控网页、SQLite 记录、温度灯光和独立调速实际机械效果尚需部署观察**，不能用这些既有证据代替。

本轮自动验证使用临时 proc／sys／数据卷、内存快照、替身原厂执行者与本地浏览器，不连接 NAS，不执行原厂二进制，不做真实 ioctl／I²C／电源写入。真实公开 API、配对设置保存、跨服务重建读回、网页布局与交互可在这些隔离环境验证；测试通过只能证明对应协议与软件行为，不能承诺某块主板必定提供硬件。

后续若补齐新硬件／服务来源，应先补真实能力检测、来源单位与时效、受限写入／恢复和测试，再开放模块。单凭参考 HTML 有卡片或后端有同名函数，不算适配完成。
