R1 Toolbox 是海康 R1 NAS 的开源增强工具箱。不刷原厂系统，用容器补上小屏、网页监控、完整 SMART、自定义风扇曲线、影视排序补丁和 API/MCP。

支持范围只支持安装了海康出厂系统的 HikSemi R1 NAS；其他机型或第三方系统不在当前支持范围。

不接管原厂系统

原厂 AppImage、启动脚本和厂商服务保持原样；容器停止时尝试恢复官方界面。

不只是监控

面向真实 R1 使用场景的扩展，不是一张静态仪表盘。

01 / MEDIA

影视中心排序补丁

为原厂影视库增加追更排序；显式检测、确认和备份后应用，可撤销。

02 / THERMAL

自定义温度风扇曲线

CPU／系统风扇独立配置，多选温度来源，保留原厂自动与故障回退。

03 / AUTOMATION

API / MCP

默认关闭；独立 Token 按角色、功能域、文件和来源授权，旧键不自动扩权。
