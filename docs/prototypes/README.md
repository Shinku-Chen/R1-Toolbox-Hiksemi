# 小屏交互原型

[`r1-small-screen.html`](r1-small-screen.html) 是独立、离线可打开的 HTML 设计原型，用于评审 R1 Toolbox 的 376×960 竖屏界面。参考深色卡片、点阵数字和趋势曲线，按触摸操作重新整理信息层级。

## 打开与预览

直接用 Chrome、Chromium 或 Edge 打开 HTML，无需安装依赖或启动 NAS 服务。

- 在电脑上选择「交互预览」，可点击屏幕里的底部导航、卡片和返回键。
- 选择「全部页面」，可同时查看 11 张主页面与详情画板，点击「进入此页」返回交互预览。
- 浏览器视口宽度不大于 600px 时隐藏设计说明，直接显示小屏界面。建议用开发者工具设为 376×960，并再检查 320×960。
- 可用查询参数直达详情，例如 `r1-small-screen.html?view=thermal`；总览使用 `?mode=gallery`。

也可在仓库目录启动静态预览：

```sh
python -m http.server 18733 --bind 127.0.0.1
```

打开 `http://127.0.0.1:18733/docs/prototypes/r1-small-screen.html`。静态服务只负责读取文件；停止终端进程即可结束预览。

## 页面与交互

| 底部入口 | 信息与详情 |
|---|---|
| 概览 | 本地时钟、温度提示、CPU、内存、存储、网络；进入六项核心指标、处理器与内存、历史趋势、温度与风扇 |
| 存储 | 数据盘总使用率；列出物理磁盘和单盘使用率，SMART 不可用时标注未读取，不把挂载点当磁盘 |
| 网络 | 下载、上传、接口与地址；查看宿主监听及独立的 Docker 端口映射 |
| 应用 | 容器数量、容器预览、完整示例列表、容器详情 |
| 温度 | 温度传感器、风扇转速与参考状态；CPU／系统风扇分别以单行五档快速切自动／低／中／高／手动 |
| 设置 | 亮度、自动息屏与唤醒、灯光色相／亮度／原生模式（关闭、常亮、彩虹、呼吸）、网页设置入口，以及进入二级页的电源管理 |

界面采用单列滚动与六项底部导航（376px 单行、320px 三列两行，最后一项为“设置”）；主页面不显示顶部栏，详情页只保留返回栏，电源管理放在设置页。主要点击目标不小于 56×56px，中文正文为 22px、导航标签 18px、主要按钮 22px；辅助说明和单位提升到 14–17px，按钮文字尽量填满可用宽度。屏幕亮度、灯光亮度和色相滑块共用同一宽度与 56px 触控区、16px 轨道和 28px 圆形滑块。点阵由内联 SVG 绘制，不依赖远程字体。详情返回保留原页滚动位置，左右滑动作为补充操作，不替代可点击导航。

亮度、色相、亮度和风扇档位只修改原型内的演示状态；自动息屏时间同样只保存在当前页面。息屏显示黑色遮罩，轻触唤醒。设置页点击“电源管理”进入二级页，再分别选择重启或关机；点击后显示确认框，确认后进入 5 秒倒计时，切换页面仍可取消。倒计时结束仅提示演示结束。

## 接入边界

所有数字、告警、磁盘、容器和地址均为标明的演示数据，本地时钟除外。此文件不接入 API、不读取控制令牌、不请求硬件，也不写入部署配置；CSP 禁止网络连接。正式小屏目前仍是上一版五标签实现；本轮六标签、独立温度页和设置页电源管理先在此原型评审，确认后再同步到 `ui/index.html` 与 `ui/assets/panel.*`。本文件保持离线设计档案，不进入 UI bundle，也不参与生产运行。

正式小屏继续使用既有 API、鉴权与硬件预检。告警必须来自真实监控结果；本轮原型不展示虚拟机。SMART 只使用缓存、不得唤醒休眠盘；未知读数保留 `--`。风扇 RPM 保留未知，不能把目标百分比当转速。功率只示例 CPU 封装的 RAPL 读数，不代表整机功耗。温控曲线、灯光颜色与登录口令继续在网页配置。

## 验证

```sh
node tests/check_small_screen_prototype.cjs
```

使用 `CHROME_BIN` 指定 Chrome／Chromium；测试也支持本机 Playwright 缓存中的 Chromium。设置 `R1_PROTOTYPE_SCREENSHOT_DIR=build/prototype-screenshots` 可输出页面截图。

自动检查涵盖两种窄屏宽度、页面溢出、触摸目标、六项底部导航、物理盘（含 SMART 不可用）展示、独立温度页与双路风扇单行五档、灯光色相／亮度／模式、自动息屏、设置→电源管理二级页的确认／取消／倒计时、桌面画板和网络隔离。正式小屏的同类检查见 `tests/check_interactions.cjs`；仍需在 R1 触摸屏检查字形清晰度、手势触发和实际亮度响应。
