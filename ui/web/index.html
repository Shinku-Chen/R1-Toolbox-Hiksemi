CPU 与系统风扇

两路独立设定，多选温度源取最高。

独立温控 · 两路分别执行

CPU 与系统风扇

每一路独立选择模式、温度源和输出，不使用共用的原厂 fan_mode。

温控参考值 = 所选有效来源的最高温度。CPU 与硬盘均为 °C，但正常范围不同，混选时 CPU 可能主导。缺测、过期及过热保护由后端执行；目标输出百分比不等于实际 RPM。

温度规则：升温到达阈值后下一轮升档；降温带 3°C 迟滞。低温保持最低安全输出，不停转。全速固定为 100%；独立 CPU 保护上限不高于 80°C；保护读数缺失也会请求全速，保护规则优先于用户阈值。
